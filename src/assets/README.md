# Steam OpenID button

`steam-sign-in.png` is Valve's 180 × 35 “Sign in through Steam” button,
downloaded from `https://community.fastly.steamstatic.com/public/images/signinthroughsteam/sits_01.png`.
Valve links this asset from the “Valve Brand and Links” section of
`https://steamcommunity.com/dev?l=german` for sites using Steam OpenID.
