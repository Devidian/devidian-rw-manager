# Manager frontend 1.9.0-rc.1

This release candidate adds the super-admin Server Duplicates panel. It shows strong and possible matches, lets an admin select multiple source entries, previews the target ID, current address, favorites and statistic hours, and requires confirmation. Former server links and anonymous browser favorites follow the canonical ID.

Requires Manager backend 0.9.0-rc.1. Deploy the backend first. Roll back to frontend 1.8.1 and backend 0.8.0 if runtime checks fail before a merge. A completed merge needs the pre-merge MongoDB backup for data rollback.

Validation: TypeScript, lint, production build and 107 frontend tests passed. Real-browser acceptance of candidate groups and confirmation remains pending.
