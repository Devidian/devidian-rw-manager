# Manager frontend 1.8.0-rc.4

This release candidate prevents the server statistics charts from flashing during live status updates. Statistics are refreshed every 30 seconds independently of the live server status. Existing charts remain mounted during refreshes, unchanged values do not trigger chart updates, and changed values render without entry animations.

Requires no backend change. Roll back to frontend 1.8.0-rc.3 if needed.

Validation: TypeScript check, 105 frontend tests, lint, and production build. On the deployed frontend, open a server's Statistics tab and verify that both charts remain visible through live status updates and a statistics refresh while values still update when new samples arrive.
