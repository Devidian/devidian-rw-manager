# Manager frontend 1.8.0

This stable release includes the accepted 1.8.0 release candidates: saved public Global Intercom subscriptions, calendar-based statistics, stable charts, player profiles and history, deduplicated global online players, optional satellite map selection, stored player metrics in server details, OZ social preview and favicon, and Steam sign-in without a browser-side Steam Web API request or exposed API key.

Requires Manager backend 0.8.0. Deploy the backend first. The public preview image is shared by all routes; social platforms may retain a cached older preview after deployment. Roll back frontend and backend together to the last accepted RC pair if necessary.

The 1.8.0-rc.7 frontend passed 104 tests, lint, and production build. Production RC validation confirmed healthy startup, public OG metadata and image, and the absence of Steam Web API references in the delivered JavaScript. The user accepted the icons and social preview and confirmed Steam login without CORS errors.
