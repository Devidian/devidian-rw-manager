# Manager frontend 1.9.1-rc.1

Player profiles open only for signed-in users. Guests are sent to sign-in on
direct profile visits, player names no longer link to profiles, and public
views show only the first and last Steam-ID digit. Distinct player names remain
separate when their masked IDs coincide.

Requires Manager backend 0.9.1-rc.1 for matching REST and WebSocket privacy
behavior. Deploy backend first. Roll back both services to backend 0.9.0 and
frontend 1.9.0 if test acceptance fails. No data migration is required.

Validation: all 112 frontend tests, lint without errors, and production build.
The separate TypeScript check still reports existing errors outside this RC.
Test guest profile redirect, guest ID display, login, profile history, and live
updates in the test environment.
