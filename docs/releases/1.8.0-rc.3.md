# Manager frontend 1.8.0-rc.3

This release candidate shows each online player only once in the global player list and its navigation count when multiple server addresses return the same player. The row links to the address most recently advertised by the master list, so the link follows a later address switch. Individual server details and stored server records remain available.

Requires no backend change. Roll back to frontend 1.8.0-rc.2 if needed.

Validation: TypeScript check, frontend tests, lint, and production build. Verify Antropia in the live global player list and confirm that its player appears once with the current server link.
