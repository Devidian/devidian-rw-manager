# Manager frontend 1.9.0-rc.2

Improves the super-admin duplicate review table: online and offline states have distinct colors, game mode and OS share a column, and first and last seen share a compact two-line column. A group-wide select-all action selects every source except the oldest target; server names render their Rising World rich-text colors and formatting within constrained columns.

Requires Manager backend 0.9.0-rc.2 for the corrected candidate and statistics behavior. Deploy after that backend image. Database history rollback requires the MongoDB backup.

Validation: TypeScript, production build, lint with no errors and 109 frontend tests passed.
