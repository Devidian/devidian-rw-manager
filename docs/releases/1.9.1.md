# Manager frontend 1.9.1

This stable release includes the accepted player-profile privacy RC. Player profiles require sign-in. Guests opening a profile directly are redirected to login, player names do not link to profiles, and public views show only the first and last Steam-ID digit. Players with different names remain distinct even when their masked IDs match.

Requires Manager backend 0.9.1 for matching REST and WebSocket behavior. Deploy backend first. No data migration is required; restore backend 0.9.0 and frontend 1.9.0 together for image rollback.

Validation: frontend RC.1 passed 112 tests, lint without errors, production build, and GitHub CI. Public browser checks confirmed the guest profile redirect, masked IDs and absent profile links on the player list and statistics page. The user accepted signed-in profile access and guest behavior on 2026-11-13. The separate TypeScript check still reports existing errors outside this release.
