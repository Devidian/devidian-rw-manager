# Manager frontend 1.8.0-rc.2

This release candidate adds the optional satellite map base-layer switch and player server history. Server names on player profiles now use the same RichText formatting as server cards. It retains the Global Intercom and statistics behavior from 1.8.0-rc.1.

Deploy after Manager backend 0.8.0-rc.2. Without satellite tiles, the terrain map remains the available base layer. Roll back to frontend 1.8.0-rc.1 if needed; the backend and renderer additions remain compatible.

Validation: 23 test files and 103 tests, lint without errors, and production build. Verify the live player profile and map layer switch after deployment.
