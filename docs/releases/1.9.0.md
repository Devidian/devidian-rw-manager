# Manager frontend 1.9.0

This stable release adds the Steam super-admin Server Duplicates panel. It shows strong and possible candidates in expandable groups, supports selecting all source entries, previews the merge and requires confirmation. The compact detail table highlights online/offline status, combines game mode with OS and first/last seen timestamps, and renders Rising World name formatting and colors. Former server links and anonymous favorites follow the canonical ID.

Requires Manager backend 0.9.0. Deploy the backend first. A completed merge needs a MongoDB backup for data rollback; reverting the frontend alone does not undo a merge.

Validation: frontend RC.2 passed 109 tests, TypeScript, production build, lint without errors and GitHub CI. The public RC.2 frontend was healthy with zero restarts and the duplicate-review route returned HTTP 200.
