# Manager frontend 1.8.0-rc.1

This release candidate adds saved public Global Intercom channel subscriptions and player profiles showing current server activity and available playtime. Global statistics now use the selected local calendar month or ISO week. Unchanged chart values no longer trigger a redraw.

Requires Manager backend 0.8.0-rc.1 for saving channel subscriptions. Existing `#GLOBAL` and `#WEB` channels continue to work. Playtime appears only when native server player data provides it.

Validation: TypeScript check, frontend tests, lint, and production build. Deploy the backend before this frontend. Roll back to frontend 1.7.1-rc.3 with backend 0.7.1-rc.2 if needed.
