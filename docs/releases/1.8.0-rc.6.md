# Manager frontend 1.8.0-rc.6

This release candidate replaces the remaining Lovable branding in page metadata and the browser favicon. Shared links now use an OZ Server Manager preview image, title, and description on Open Graph and Twitter/X. The preview is generic for all routes, including individual server links.

Requires no backend change. Roll back to frontend 1.8.0-rc.5 if needed. Social platforms may keep an older preview in their link cache after deployment.

Validation: lint (0 errors, 41 existing warnings), 106 frontend tests, production build, and verification that the built HTML references the bundled favicon and preview image without Lovable metadata. The separate `tsc --noEmit -p tsconfig.app.json` check currently reports six errors in unchanged TypeScript files; CI does not run this check.
