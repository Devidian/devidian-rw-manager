# Manager frontend 1.8.0-rc.7

This release candidate retains the OZ metadata and Discord preview from 1.8.0-rc.6. Steam sign-in no longer requests GetPlayerSummaries from the browser or embeds a Steam API key in the JavaScript bundle. The backend resolves the optional persona name and verifies the OpenID response.

Requires Manager backend 0.8.0-rc.3 with `STEAM_OPENID_RETURN_ORIGIN` and optional `STEAM_API_KEY`. Deploy the backend first. Roll back both Manager services together to frontend 1.8.0-rc.6 and backend 0.8.0-rc.2 if needed; the older frontend requires its former key environment setting for persona lookup but still encounters Steam's browser CORS policy.

Validation: 104 frontend tests, lint without errors, production build, and inspection of the built assets for Steam API key placeholders and direct Steam Web API calls.
