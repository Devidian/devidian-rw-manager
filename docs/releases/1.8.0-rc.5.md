# Manager frontend 1.8.0-rc.5

The online players table in each server's Players tab now shows the player's stored permission group, playtime, health, hunger, and thirst where available. Values come from the existing server database player response and are matched to online rows by UID. Missing database values show placeholders; no additional request or live metric feed is introduced.

Requires no backend change. Roll back to frontend 1.8.0-rc.4 if needed.

Validation: TypeScript check, 106 frontend tests, lint, and production build. On the deployed frontend, compare a server's online player row with the corresponding database row below it; verify matching values and placeholders for players without a database record.
